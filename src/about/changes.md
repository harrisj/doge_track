# What's Changed?

This is not a definitive list (for that you can always do diffs on the [GitHub repo](https://github.com/harrisj/doge_track)), but it's automatically generated by looking at the git log for this project to see if there are new IDs added (note: it'll also think a records is new if it's moved ot a different part of the file). I do hope it is helpful to see what's been added if you come back to the project after some time away.

**Important Note:** Since this project is built on information from news sources and court documents, I may add events that occurred weeks or even months earlier from the time that I add them to the system. I also may be backfilling information based on new names or events. It is not a bug.
